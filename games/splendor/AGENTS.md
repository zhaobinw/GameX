# Splendor 经典基础版

- 复刻目标固定为经典版基础游戏（Marc André / Pascal Quidault），2–4 人。
- 不添加扩展、Duel、原创卡牌、额外胜利条件、回合上限或简化行动。
- 官方规则优先于开源实现；研究证据和差异记录在 `docs/research.md`。
- 数据修改需逐卡对照来源，不能用颜色轮换或组合生成来猜测牌库。
- 不把测试通过描述为已完成官方认证或全部视觉复刻。
- 规则引擎不依赖 DOM；观察数据不得包含牌堆顺序、随机种子或对手暗牌。
- 原画缓存位于忽略目录 `web/assets/classic/`；来源、校验值与第三方声明必须保留。
- 验证命令：`npm test`、`npm run simulate -- --games 30`；界面变更另做浏览器验证。
