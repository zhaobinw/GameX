- UI 原图可加载，不代表全部 100 个卡面均已与实体牌人工签核。
- 在线安全、多人联网、压力负载、训练算法和跨设备同步不在此次范围。
- 当前本机服务是单进程内存状态；停止服务不会保留未完成对局。
