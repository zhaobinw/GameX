攻略如何帮助训练

攻略先转为估算拿牌所需回合、目标卡折扣价值、黄金与预留压力、贵族距离和对手抢分威胁等特征；教师策略产生示范，神经网络先模仿，再通过自我对弈 PPO 学习。教师建议会逐步减弱，不作为永久行动规则。

一级与二级卡并非完整五色对称，因此不会随意交换颜色生成假样本。“421 优先”“贵族弱”等只作为可被反驳的经验，不是必须执行的规则。

算法与指标说明

模型：共享状态编码器 + 逐个合法行动评分 + 价值头。PPO 根据完整对局胜负学习，混合当前模型、历史模型和贪心基线作为对手。每个合法支付组合都保留；没有裁剪合法行动数量。

“截断”是训练采样预算耗尽，不是游戏判平，不计入胜率和策略梯度。胜局份额在共同获胜时按人数平分。参数变化用于确认优化发生，不等于棋力提升。基础 PPO 使用固定购牌偏好；攻略版使用教师预训练和按玩家分别计算的 GAE，推理时不把教师评分加到策略概率中。
