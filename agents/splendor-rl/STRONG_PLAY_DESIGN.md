# 面向强人类对手的 Splendor 训练设计

## 结论：用攻略起步，用对抗超越攻略

推荐路线是 **攻略教师 → 策略蒸馏 → 有历史对手的自我对弈 → 信息集搜索改进教师 → 再蒸馏 → 盲测强人类**。不能用“奖励 AI 买 421”代替真正的胜负学习，也不能把超过贪心基线解释为超越人类。

本次已实现前三步的第一版，包括新增策略特征、可执行教师、预训练、按玩家分别计算 GAE、逐步减弱的教师辅助损失和独立评估。信息集搜索、更大的集合网络、自动冠军晋升和人类实战协议是后续阶段，尚未实现；不把路线图当作交付成果。

## 上一版为什么弱

1. 拿取动作主要是颜色计数向量，模型要从零学出“拿这些颜色可缩短目标卡几个回合”。约千局难以获得这种规划能力。
2. 固定的购买偏好不区分目标折扣、卡牌效率、对手威胁和占用预留槽，可能买下无用的零分牌。它也不是攻略知识。
3. 全局扁平 MLP 缺乏卡牌之间的关系表示。完整对局 Monte Carlo 回报正确但方差大，每个决策只看到相同的终局信号。
4. 对手太弱且单一，历史池规模小。对贪心胜率低应先用教师/专家初始化，而不是盲目加大网络和训练时长。
5. 老评估采样随机流跨并行环境共享，改变并行数会改变动作抽样序列。本次改为每局每席独立随机流；交换座位与保持开局才有可比性。

## 怎样把这篇攻略变成知识

来源是用户提供的一刻馆桌游《璀璨宝石攻略（一）卡牌上的五色循环》。下面是本项目对其策略主张的算法化解释，不是作者提供的算法，也不是官方裁定的最优策略。

| 攻略主张 | 可计算表示 | 训练用途与限制 |
|---|---|---|
| 21/1111 补色，零分卡要服务目标 | 市场高分卡的颜色需求、买卡后目标距离的变化 | 教师评价发展卡的边际折扣价值，而非按零分牌数量发奖励 |
| 421 适合开局 | 实际成本形状、当前折扣/手牌、预计拿取次数 | 成本形状是特征；不强制预留/购买所有 421 |
| 73 高效但会被 10 枚上限卡住 | 折后总成本、颜色缺额、不可从银行获得的数量、超额 | 估计可达性；不是把攻略给出的回合数当所有局面的常数 |
| 蓝绿、白黑红搭配 | 使用真实牌库与当前市场的成本向量、颜色需求强度 | 不硬编码某种颜色总是更强；随市场与对手变化 |
| 贵族要看需求重叠 | 最近两位贵族的剩余折扣距离 | 不奖励无目的堆卡；3 分是否能收尾仍按规则考虑 |
| 黄金与预留位置很重要 | 稀缺颜色、黄金替代、手牌上限、预留槽数 | 为过早预留难完成高分牌计入节奏成本 |
| 中后期抢分、补分 | 即时分数、15 分阈值、对手公开分数和可购买威胁 | 教师只能估算；真正结算仍由规则引擎完成 |

**不能随意做颜色置换增强。** 对官方数据做整环旋转后，一、二、三级分别仅 25/40、19/30、20/20 能找到相同结构的卡。某一层对称不意味着整个对局对称。90 张牌/贵族/银行/手牌/策略必须一起满足等价变换才能安全增强。已提供 `scripts/audit-colors.mjs`，目前不做这种增强。

## 当前已实现的 V2

### 输入和教师

保留原合法观察，再增加 9 维上下文和 26 维候选行动特征：总计 **433 维状态、73 维行动**。只使用当前公开市场、自己手牌、公开折扣/分数和贵族。没有读取真实暗牌或下一张补牌。

教师对每个合法行动做**公开信息下的静态操作后估算**：筹码变化、购牌折扣和分数、目标卡预计可达回合、贵族距离、对手抢分威胁与预留压力。市场未知补牌不参与计算。这个估算不是完整搜索，也不是精确的胜率或最少回合数。

教师将“完成某张卡的预计回合”转成分数/节奏效率，用真实成本与银行稀缺度修正。动作值包含即时分数、折扣边际价值、目标推进和威胁阻断等项。系数在 `knowledge.mjs` 中公开，属于可被实验否定的启发式。教师评分作为软标签，**不在推理时直接加进网络 logit**。所有合法动作仍保留。

### 预训练

默认用 64 局教师自我对弈采集示范（该局所有席位都可贡献示范），按 `softmax(教师评分 / 0.25)` 蒸馏 30 epochs。训练损失为交叉熵。冻结预训练完成时的模型作为这一轮的起点基线。

这种做法是 [Policy Distillation](https://arxiv.org/abs/1511.06295) 思路的具体应用；我们的教师是手写策略，不冒充论文中的深度 RL 专家。未来应加入多种教师（抢分、发展、重叠贵族、抢关键资源）和专家/搜索轨迹，避免一个教师的系统偏见覆盖全部策略。

### 强化学习

保留 PPO clip 0.2、Adam 3e-4、entropy 0.01、gradient clip 0.5。使用 [GAE](https://arxiv.org/abs/1506.02438)，λ = 0.95、γ = 1，在**每个玩家自己的决策序列**上计算：

`δ_t = r_t + V(next own decision) − V_t`

`A_t = δ_t + λ A_(t+1)`

完成对局的最后一步给真实终局效用，终局 bootstrap 为零；拿取、归还、贵族选择仍是合法决策节点。对手的时间步不会串入当前玩家的 advantage。完整轨迹中的 critic target 为 `A + V_old`。

训练时保留逐渐减弱的教师交叉熵：`β_g = 0.1 × exp(−generation / 50)`；最终由胜负目标主导。提供 `--teacher-weight 0` 和 `--warmup-epochs 0`，用于消融。续训按绝对代数衰减，不重新放大教师权重。

奖励仍然只有真实胜负；不因买牌、拿黄金、争贵族直接发额外奖励。若后续加入 potential shaping，应使用固定潜势的 `γΦ(next)−Φ(now)` 并确保终局 Φ=0。尤其在完整 MC、γ=1 下，潜势项会望远镜消去，不能把它宣传为自动产生更强监督；随意给分可能教出刷牌而不赢的策略。

### 对手分布与推理

除保证一个当前模型席位外，其余席位抽样为当前模型 30%、历史池 35%、攻略教师 25%、旧贪心 10%。学习席与先手独立轮换。当前实现保留初始模型及近期快照，还不是 PFSP 联赛。

训练用随机策略；评估分别报告随机采样和 argmax 确定性出手，不能把确定性新模型与随机旧模型混在同一栏比较。在需要混合策略的不完全信息局面，argmax 未必最难被利用，因此最终部署应通过对抗测试校准温度/搜索策略。

## 通往强人类水平的下一阶段

### A. 先建立可靠的对手联赛

维护风格多样的启发式、预训练教师、历史冠军、近期模型和专门找漏洞的对手。按胜率分段优先抽取有学习价值的对手，同时保留一定弱对手和旧冠军，防止灾难遗忘与策略循环。新冠军必须通过独立开局、交换座位、足够样本和置信区间，不以某代 8/20 局胜率晋升。

第一道门槛建议：对随机/旧贪心稳定高胜率，对攻略教师和旧冠军不退步，零非法动作、零暗牌泄漏、完整率接近 100%。先针对二人做出强度，再独立训练/评估三人与四人；多人不能沿用二人零和均衡的结论。

### B. 升级关系模型，而不是只加宽 MLP

建议 1–3M 参数作为下一档实验预算，具体大小由吞吐与消融确定：

- 发展卡、贵族、玩家、银行分别编码成 token；用集合注意力读取真实颜色/费用关系。
- 每个候选行动作 query，对公开卡牌和玩家 token 做交叉注意力；输出策略与价值。
- 用 GRU 或受控历史编码保留公开预留、购买、拿取的线索。模型记忆只来自可见历史。
- 辅助头学习自己的卡牌可负担性、贵族距离、公开目标回合估计；这些是表示学习监督，不能替代胜负奖励。
- 可进一步按“行动目标 → 支付方式”做分层策略，避免一张牌仅因合法黄金支付组合更多而在平坦 softmax 中获得更大初始概率；仍必须保留全部合法组合。
- 开展等算力对照：现有特征 MLP / 集合网络 / 有历史记忆版本，不先假设 Transformer 一定更强。

### C. 信息集搜索与专家迭代

借鉴 [Expert Iteration](https://arxiv.org/abs/1705.08439)：网络给快速先验，搜索给更好的行动分布，再将改进策略蒸馏回网络。该论文的游戏条件不能直接当作 Splendor 理论保证。

搜索只能从公开历史构建一致的隐藏状态样本：移除已知公开卡、自己手牌和已知预留，其余未知位置抽样。所有根行动在同一组样本上比较；每个模拟对手只能看到该座位在模拟世界中合法获得的观察。不能拿真实牌堆顺序跑 MCTS，也不能让根玩家针对每个假设暗牌分别选择行动后再当成现实策略。

从固定 64/128/512 模拟预算做消融，测同一思考时间下对无搜索模型的提升。简单 determinization 会有 strategy fusion 和 non-locality，需信息集节点或相应修正；不能把“多采样几个隐藏世界”称为已解决不完全信息。

### D. 防止先验成为上限

教师只用于起步，后期降低 β；在同样训练局数下比较保留教师、衰减教师、完全去教师。引入搜索/联赛失败局作为新示范，允许网络推翻“贵族弱”“某类牌差”等局势相关经验。

如果大规模自我对弈仍出现策略循环和可被针对的问题，再研究适用于不完全信息的正则化/平均策略方法；[DeepNash](https://arxiv.org/abs/2206.15378)展示了相应研究方向，但它在 Stratego 的结果并不证明我们的 Splendor 系统具备同样能力。

## 验证“战胜人类”的协议

先冻结模型、思考时间与规则版本，再进行独立实战。建议招募有可验证经验的玩家，双向轮换座位、随机开局、足够数量的独立局，并按人和开局做分组统计。测试种子/轨迹不回流训练，直到这一轮评估结束。

最终报告需包含：对手水平、人数模式、游戏数、共同胜利处理、胜率和置信区间、完整率、每步耗时及硬件。训练胜率、对单一贪心的胜率、教师策略胜率都不是人类成绩。当前未做任何人类对战测试；“最强”只能定义为固定规则、对手集合和算力预算下经验证的冠军，不能保证世界最强。

## 复现实验与消融

```bash
# 本次实现：攻略示范 + GAE PPO
.venv/bin/python train.py --knowledge --warmup-episodes 64 --episodes 32 --updates 12 --eval-games 20
# 去掉预训练和教师辅助损失，保留相同结构特征与对手池
.venv/bin/python train.py --knowledge --warmup-epochs 0 --teacher-weight 0 --episodes 32 --updates 12 --eval-games 20
# 新种子留出评估；加 --deterministic 单独测试确定性推理
.venv/bin/python train.py --evaluate runs/模型/latest.pt --eval-games 400 --eval-seed 881171
# 教师上限对照，不能冒充神经网络成绩
.venv/bin/python train.py --evaluate runs/攻略版/latest.pt --teacher-policy --eval-games 400 --eval-seed 881171
```

已使用的 881171 是这次报告的留出集，后续调参不能继续把它当全新测试集。先预注册下一组种子、评价模式与停止条件，再继续优化。
