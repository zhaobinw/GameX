# Splendor 强化学习

- 复用原规则引擎；模型只输入 observe(currentPlayer) 与合法行动的编码，不输入牌堆顺序、种子或对手暗牌。
- 不裁掉黄金支付组合、归还或贵族动作来缩减行动空间。
- 将采样截断、真实平分胜利、真实终局分开；不把截断轨迹当平局或有效完整训练样本。
- 实验记录配置、随机种子、模型/数据/源码版本、对手、完成率及独立评估样本数。参数更新不是棋力提升证据。
- 权重、完整回放和训练输出保留于忽略目录 runs；小型指标与报告可提交 experiments。
- 修改训练后运行 node --test tests.mjs 和 Python unittest；涉及规则桥接同时运行游戏原测试与 30 局模拟。
- UI 修改按游戏项目约定做浏览器验证。测试训练不要更改用户 4173 的对局。
