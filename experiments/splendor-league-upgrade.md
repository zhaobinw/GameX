# Splendor 联赛升级实测（2026-09-12）

本轮完成研究、真人败局诊断、多策略联赛、稳定化 PPO、留出选模及牌桌接入。最终模型为 `league-v4-stable/best.pt`（旧版第 12 代继续更新 64 次，牌桌显示第 76 代）。权重及真人完整复盘留在本机。

## 最终独立结果

每种对手 200 局，100 副牌局成对交换座位。下表分母为全部安排局数，超出采样预算的局按零计入；共享胜利按份额计算。

| 对手 | 旧版 | 联赛版 | 联赛版截断 |
|---|---:|---:|---:|
| 旧版神经网络 | 50.00% | 59.00% | 1 / 200 |
| 攻略教师 | 47.00% | 55.50% | 0 / 200 |
| 冲分型 | 44.50% | 54.75% | 2 / 200 |
| 发展/贵族型 | 52.25% | 61.75% | 0 / 200 |
| 拦截型 | 49.50% | 60.25% | 1 / 200 |
| 贪心基线 | 85.00% | 85.00% | 2 / 200 |

六类对手平均提升 **8.0 个百分点**，按牌局配对 bootstrap 的 95% 区间为 **3.79–12.21 个百分点**。

在查看这批最终结果之前，另行固定新增 600 局、300 副新牌局的旧版正面对照。合并 800 局后的胜局份额为 **60.56%**，95% 区间 **57.06%–64.00%**；合计 2 局截断。

两项发布门槛均通过，新模型登记为本机默认对手。这是相对旧模型及这些基线的进步，不是已经证明能稳定战胜高手，更不是“世界最强”。

## 训练与失败结果

V4 训练种子 721019，验证种子 10721019，留出种子 20721019，额外复验种子 30721019。8 个并行环境，64×128 = 8192 局训练，完成 8165 局，其余截断轨迹不进入训练。每 8 次更新进行每对手 120 局验证，最终选中第 64 次更新。CPU / PyTorch 2.14.0 / Python 3.12.12，98,178 参数。

此前 V3 训练 3072 局，3061 局完成。其留出平均下降 1.58 个百分点，区间跨零；未发布。没有隐藏这次失败，也没有用其留出种子重新选 V4。V4 增加弱教师损失、旧策略 KL 约束并降低熵奖励。
