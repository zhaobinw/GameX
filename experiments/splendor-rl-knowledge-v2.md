# 攻略先验训练 V2：对照与消融

日期：2026-09-12。[完整算法设计](../agents/splendor-rl/STRONG_PLAY_DESIGN.md)；[原始汇总与配置](splendor-rl-knowledge-v2.json)；[牌库颜色审计](splendor-color-audit.json)。模型保存在 `agents/splendor-rl/runs/knowledge-v2-dev/latest.pt`，权重 SHA-256 见 JSON。

## 本次改动

在 V1 的真实可见观察与完整合法动作之上，增加公开目标可达性、折扣边际价值、贵族距离、预留/黄金压力、对手抢分等特征。状态 433 维、行动 73 维，MLP 参数 98,178。新增教师软标签蒸馏，再用按玩家计算的 GAE PPO 与衰减教师辅助损失继续训练。

- 教师：根据用户提供的一刻馆攻略作算法化解释；不是官方最优策略。
- 示范：64 局教师自我对弈，3,735 个状态行动示范；30 epochs 蒸馏。
- 强化学习：12 代 × 32 局，共 384 局，383 局正常结束，1 局截断。
- 学习奖励仍为终局胜负，不因买 421、拿黄金或积攒发展卡额外奖励。
- 教师评分不作为推理 logit；表中模型成绩由神经网络输出产生。网络使用由攻略启发的结构化特征，所以仍是带领域知识的模型。
- 评估随机流改为每局每席独立，已测试改变并行 worker 数不改变评估结果。贪心排序从模型 prior 中解耦，防止 V2 删除固定 prior 时把对手意外削弱。

## 400 局留出对照

训练监控种子 908172，留出种子 881171。200 个开局各交换座位，共 400 局；模型在留出评估之前冻结。未根据该留出集继续调参。以下分母为完整结束局，共享胜利按份额计算。

| 方法 | 出手方式 | 完成 / 计划 | 对旧贪心胜局份额 |
|---|---|---:|---:|
| V1 第 42 代 | 随机策略 | 400 / 400 | 34.75% |
| V2 同特征与对手池，去掉示范预训练和教师辅助损失，12 代 | 随机策略 | 398 / 400 | 22.36% |
| V2 仅攻略预训练 | 随机策略 | 398 / 400 | 62.31% |
| V2 攻略预训练 + 12 代 PPO | 随机策略 | 397 / 400 | 65.99% |
| V1 第 42 代 | 确定性 argmax | 398 / 400 | 40.08% |
| V2 攻略预训练 + 12 代 PPO | 确定性 argmax | 400 / 400 | **81.75%** |
| 手写攻略教师，非神经网络 | 确定性规则 | 400 / 400 | 86.00% |

另外，新模型以确定性方式直接对抗攻略教师，400 / 400 完成，胜局份额 **48.375%**。它已接近这个教师的水平，但没有证据说超越教师，更没有人类实战结果。

V1 在旧报告的 22% 和本报告的 34.75% 使用了不同测试开局与修正后的独立随机流，不应拿两者当同条件对照。本表中的旧/新模型都按相同的新协议重新测试。

## 能得出什么结论

以开局的两个交换座位结果为配对单元、仅纳入双方均完成的整对，10,000 次 bootstrap（种子 71）：

| 比较 | 完整配对数 | 配对平均差 | 95% 区间 |
|---|---:|---:|---:|
| V2 随机 vs V1 随机 | 197 | +31.98 pp | +25.13 至 +38.58 pp |
| V2 确定性 vs V1 确定性 | 198 | +41.79 pp | +35.61 至 +47.85 pp |
| 仅预训练 vs 去先验消融 | 196 | +39.80 pp | +34.18 至 +45.41 pp |
| 预训练 + PPO vs 仅预训练 | 195 | +3.85 pp | −3.08 至 +10.51 pp |

可支持的结论：**攻略先验这一整套初始化显著改善了本次开局集合上的早期表现；12 代 PPO 相对于预训练的额外收益仍不确定。** 不能把主要提升全部归功于 PPO。

教师示范增加了 64 局数据和 30 epochs 计算，所以这里是同强化学习代数下的样本效率比较，不是等总算力消融。仅训练了一个初始化随机种子，多个训练种子的稳定性仍待验证。评估开局局数多也不能代替独立训练重复。

截断不是平局，不参与胜率。本次 V2 随机评估的 3 个未完成局全部按最坏/最好情况计入时，胜局份额范围为 65.50%–66.25%；其余方法的少量截断同样要保留可见。置信区间只描述已完成配对的开局波动，不能涵盖全部训练不确定性。
